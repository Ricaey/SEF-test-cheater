# SmartQuiz Local - 离线题库助手

SmartQuiz Local 是一个基于 React + Vite 开发的响应式 Web 应用，旨在帮助学生高效查询课程小测题库。它支持文本检索和完全本地运行的图片 OCR 识别。

## ✨ 主要功能

- **本地 OCR 识别**：集成 `Tesseract.js`，识别过程完全在浏览器本地运行，不消耗任何 API 额度，隐私安全。
- **本地急速检索**：使用 `Fuse.js` 进行高精度模糊搜索，毫秒级响应。
- **多语言支持**：OCR 引擎支持中英文识别（Chi_Sim + Eng）。
- **零配置启动**：不再强制要求 Gemini API Key，下载即用。

## 🚀 快速开始

### 1. 环境准备
确保你的电脑已安装 [Node.js](https://nodejs.org/)。

### 2. 安装依赖并运行
```bash
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev
```
访问 `http://localhost:3000` 即可开始使用。

## 📖 使用指南

### 文本搜索
直接在搜索框输入题目的关键词，数据库会自动联想。

### 图片搜索 (本地 OCR)
1. 在网页/文档中截取题目图片。
2. 在搜索页面直接按下 `Ctrl + V` 粘贴。
3. 浏览器会自动初始化 OCR 引擎并完成识别（首次运行会下载语料包）。

### 数据管理
编辑 `src/data/question_bank.json` 即可更新你的私人题库。
